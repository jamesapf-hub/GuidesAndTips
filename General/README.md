# How to Use This Portal Guide

## Overview
Welcome to the central repository for all operating guides, tips, and standard operating procedures (SOPs). This repository is configured to help you quickly search, read, and print guides for standard system tasks and IT workflows.

### Key Features
* **Rich Markdown Guides:** Automatically parses and renders documentation sheets directly in the Bento-style docs tab.
* **Portal-Wide Integration:** Interacts seamlessly with the navigation menu and searches tags across categories.
* **Central File Browser:** View folder structures, inspect code/text, and download file folders as \.ZIP\ bundles.

## Prerequisites
System Support: Any modern browser (Chrome, Edge, Firefox, Safari)
Access Level: Standard IT staff membership
Dependencies: None (uses standard web standards)

## Walkthrough & Usage Guide

### 1. Step-by-Step Instructions

#### How to Navigate the Browser
1. Click **Repos** in the left sidebar, and select **Guides & Tips**.
2. Click on the **General** folder card to browse its files.
3. Select the **How to Use This Portal** guide from the list.
4. Read the parsed guide under the **Walkthrough Guide** tab, or switch to **Source Code** to inspect the raw Markdown file.

### 2. Creating New Documentation
* Create a new folder for the specific category (e.g., \M365\ or \Networking\).
* Write a new Markdown (\.md\) file following this structure (Overview, Prerequisites, Walkthrough) to keep documentation consistent.
